# Gloss Source: Payne Smith Syriac Dictionary

## Provenance
**Primary reference:** Payne Smith, R. (ed. J. Payne Smith).
*A Compendious Syriac Dictionary*. Oxford: Clarendon Press, 1903.
**License:** Public domain (pre-1928 publication, published 1903)

**Cross-reference:** CAL — Comprehensive Aramaic Lexicon,
Hebrew Union College–Jewish Institute of Religion (cal.huc.edu).
Freely searchable online; individual entry data referenced for verification only,
not redistributed.

## Files
Proof-verse glosses are stored in the Peshitta source directory:
`../../peshitta/payne-smith-proof-verses.tsv`

At scale, the import pipeline will reference CAL entry IDs as pointers to Payne Smith
entries, rather than reproducing dictionary text. The CAL is used as a lookup service
only; no CAL data is stored in this repository.

## Usage
The Payne Smith CSD is used to provide short English glosses for Syriac word tokens
in the Peshitta column. Each gloss is a one-to-four word interlinear rendering suitable
for display alongside the Syriac text.
